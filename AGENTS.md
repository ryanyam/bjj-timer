# BJJ Timer Project Rules

## Goal

Build a reliable offline BJJ timer for Mac development and later Raspberry Pi kiosk deployment.

## Tech

- React
- TypeScript
- Vite

## Rules

- Keep changes small and focused.
- Explain the plan before editing files.
- Do not add dependencies unless I approve them.
- Do not create a backend, database, login, cloud sync, or analytics.
- Timer accuracy must use timestamps, not naive one-second decrement logic.
- Add or update tests whenever timer behavior changes.
- Run npm test and npm run build after code changes.
- Do not commit, push, or delete files without asking first.

## Learning

- Explain what changed in beginner-friendly language.
- Point out one thing I should understand from each task.
